## 1. 安装与启动

### 启动

- **双击桌面上的「一周日程」**，或从开始菜单打开。
- 已经设置过开机自启的话，登录 Windows 后它会在托盘里静默运行（不弹窗口）。
- **不要从聊天窗口/文件卡片里点这个 exe**：那种方式启动的进程会被限制写权限，
  表现为数据存到程序目录、托盘没有图标、开机启动报 `[WinError 5]`。请始终用桌面或开始菜单的图标。

### 安装位置

| 内容 | 位置 |
| --- | --- |
| 程序 | `C:\Users\<你>\AppData\Local\Programs\WeeklyPlanner\` |
| 桌面图标 | `桌面\一周日程.lnk` |
| 开始菜单 | `开始菜单\程序\一周日程.lnk` |
| 日程数据 | `%APPDATA%\WeeklyPlanner\planner.db` |
| 记账数据 | `%APPDATA%\WeeklyPlanner\finance.db` |
| 日志 | `%APPDATA%\WeeklyPlanner\logs\planner.log` |

## 2. 界面导览

### 顶部导航栏

左上角是「一周日程」的标志，右边四个标签页：

- **日程**：一周视图与任务管理（默认页）。
- **记账**：记收入/支出、查看本月概览。
- **月度总结**：每月财务报告与历史回看。
- **资金管理**：资金分区、资金调动、财务设置。

最右边两个按钮：**◐ 切换浅色/深色主题**、**⚙ 设置**（日程与提醒的设置）。

### 日程页

| 区域 | 作用 |
| --- | --- |
| 标题区 | 当前月份、本周日期范围、第几周；「今天」与实时时钟 |
| 周导航 | `‹` 上一周、`本周` 回到本周、`›` 下一周 |
| 搜索框 | 按名称/说明/备注/分类搜索（跨全部日期），回车打开结果列表 |
| 新建任务 | 打开新建对话框 |
| 筛选行 | 分类、状态、优先级、只看逾期 |
| 逾期提示 | 有逾期任务时出现红色提示条，点击可只看逾期 |
| 周视图 | 周一至周日 7 列时间轴，任务块按真实时间定位 |
| 底部状态 | 本周安排数、已排定、待触发提醒数、数据文件位置 |

**周视图里的任务块**：

- **计划时间**：实色块，左侧竖条颜色代表优先级，右上角 `2/3` 表示这是该任务的第 2 个计划时间。
- **截止时间**：虚线描边，带 `截止` 或 `逾期` 徽标，悬停可看完整信息。
- **已完成**：灰色 + 删除线 + `✓`。
- 同一天时间重叠时会自动左右分栏，不会互相遮挡。

### 系统托盘

- 双击托盘图标 → 打开窗口。
- 右键菜单：**打开日程表 / 添加任务 / 设置 / 待触发提醒 / 退出程序**。
- 关闭窗口默认只是**收进托盘**，提醒继续在后台工作；只有「退出程序」才真正结束。
- Windows 11 默认把新图标折叠在任务栏右下角的 **「^」** 里，点开拖出来即可。

## 3. 日程：任务怎么加、怎么改

### 新建任务

点右上角「新建任务」（或按 `Ctrl+N`），填写：

| 字段 | 说明 |
| --- | --- |
| 名称 | 必填 |
| 说明 | 长文本，选填 |
| 分类 | 默认「学习 / 工作 / 生活」，也可以输入自己的分类 |
| 优先级 | 普通 / 重要 / 紧急（决定任务块左侧竖条颜色） |
| 截止时间 | **必填**，精确到分钟；这是「最晚必须完成的时间」 |
| 截止前一天提醒 | 每个任务可以单独关掉（见第 5 节） |
| 计划时间 | 可以添加任意多个，见下一节 |
| 备注 | 选填 |

### 修改 / 删除 / 复制

- **点击任务块**打开任务详情，可改状态（未开始/进行中/已完成）、编辑、删除。
- **右键任务块**：编辑、标记完成/重新打开、复制任务、整体顺延一周、删除。
- 删除任务会二次确认；只删某个「计划时间」不会删掉整个任务。

### 周导航与搜索

- `‹` / `›` 切换周，`本周` 或 `Ctrl+T` 回到今天所在的周。
- `Ctrl+←` / `Ctrl+→` 同样切换周；`F5` 刷新。
- 搜索框输入后实时筛选本周视图；按回车打开**跨全部日期**的结果列表（`Ctrl+Shift+F`）。

### 筛选

- 分类：全部 / 学习 / 工作 / 生活 / 自定义分类。
- 状态：全部 / 未开始 / 进行中 / 已完成。
- 优先级：全部 / 普通 / 重要 / 紧急。
- 「只看逾期」：只显示已过截止时间的任务。

## 4. 导入课表（可选）

如果学校教务系统支持导出课表，程序可以直接把整张课表铺到周视图里：

1. 在教务系统点「导出」，保存成 `.xls` / `.xlsx` / `.csv` 文件；
2. 打开程序，点右上角「导入课表」，选择这个文件；
3. 选择「使用课表时间」或「自定义每节时间」——课表里没写节次时间时，必须自己设置每节课的起止时间；
4. 填**这学期第 1 周的星期一**（例如 2026-09-07），程序会按周次把每节课展开到具体日期；
5. 预览课程列表，确认无误后点「导入」；
5. 回到周视图就能看到课程块（背景层，按真实上课时间占高）。

课程表不会变成任务，也不占用提醒；点课程块可以看教师、地点和时间。

PDF 课表：文字版 PDF 可以直接选文件导入（程序会尽力提取）；如果提取失败或 PDF 是扫描件，请在 PDF 阅读器里全选复制，点「从文本粘贴」导入。换学期或课表变了，再导入一次即可（会覆盖旧课程，也可以先「清空课程表」）。

## 5. 计划时间与截止时间有什么区别

这两个概念**分开保存、互不影响**：

| | 计划时间 | 截止时间 |
| --- | --- | --- |
| 含义 | 打算在什么时候做 | 最晚什么时候必须交 |
| 数量 | 一个任务可以有**多个** | 一个任务只有**一个** |
| 提醒 | 每个计划时间可单独开关「开始提醒」「结束提醒」；开始提醒默认提前 10 分钟，结束提醒在结束时刻 | 可开关「截止提醒」，默认截止前一天 |
| 一周视图 | 实色块，可点选 | 虚线块 + `截止`/`逾期` 徽标 |
| 完成 | 可以逐个标记完成 | 随任务状态变化 |

**例子**：写课程报告，计划时间可以设周三 15:00 和周四 19:00 两个，每个都提前 10 分钟提醒；
截止时间设周五 18:00，截止前一天提醒会自动算好。删掉周四那个计划时间，任务还在，截止提醒也还在。

在周视图里**点击空白时间段**，可以直接按那个时间新建一个计划时间。

## 6. 提醒什么时候会弹

### 截止提醒

默认规则：**截止时间前 24 小时**提醒一次。

可以在「设置 → 截止前一天提醒方式」改成：

- **截止时间前 24 小时**（默认，例如 10 月 25 日 18:00 截止 → 10 月 24 日 18:00 提醒）；
- **前一天指定时间**（例如统一在 10 月 24 日 09:00 提醒）。

每个任务的「截止前一天提醒」可以单独关闭。

### 计划时间提醒

在任务对话框里，每个计划时间可以：

- 只填开始时间：按时间点显示，可设开始前提醒；
- 打开「设置结束时间」：变成真实起止区间，结束时间可单独开关提醒；
- 截止时间区域可以单独关闭「提醒截止」。

### 通知形式（三级兜底）

1. **Windows 系统通知**（推荐）：带「查看任务」「稍后提醒」按钮，点击回到程序对应任务；
2. **系统托盘气泡**：系统通知被拒绝时自动降级（没有按钮，但仍是系统通知）；
3. **应用内浮窗**：始终可用，带按钮，屏幕右下角，约 25 秒自动消失。

「设置 → 提醒」里可以分别开关系统通知、应用内浮窗、提示音；点「发送测试通知」可以立刻验证。

### 错过提醒怎么办

- 程序没运行（关机、退出）期间不会弹通知。
- 重新打开后，**补发窗口**（默认 12 小时）内的提醒会补发一次；
- 更早的提醒会被标记为「错过」，不会反复弹。
- 补发窗口和「稍后提醒」间隔都可以在设置里改。

### 逾期

超过截止时间后任务自动标记为逾期；每次进入逾期状态只主动通知一次，不会反复打扰。

## 7. 托盘、后台运行、开机启动、全局快捷键

### 后台与退出

- 关窗口 ≠ 退出：默认最小化到托盘，提醒继续工作。
- 想彻底退出：托盘右键 →「退出程序」。
- 也可以在设置里关闭「点击关闭按钮时最小化到系统托盘」，这样关窗口就退出。

### 开机启动

- 设置 →「开机时自动启动」，写入当前用户的注册表 Run 项，登录后以 `--minimized` 静默启动。
- 从受限环境（聊天窗口等）启动的进程写不了注册表，会提示 `[WinError 5]`；
  请从桌面/开始菜单启动后再设置。

### 全局快捷键

- 默认 **`Ctrl+Shift+R`**：在任何程序里按一次就能唤出日程表。
- 这是**系统级抢占**：程序运行期间该组合会被本程序截走（浏览器强制刷新、VS Code 重载窗口会失效）。
- 可以在「设置 → 全局快捷键」改成别的组合（例如 `Ctrl+Alt+F8`）或关闭；
- 组合已被其它程序占用（Windows 错误码 1409）时，设置会提示你换一个，而不是静默失败。

## 9. 记账模块

记账数据存在**独立的 `finance.db`**，和日程数据互不影响。

### 第一次使用：设置初始余额

1. 顶部切到「记账」；
2. 点「设置初始余额」；
3. 输入现在手里的**总金额**，再把它分配到几个资金分区（名字自己起，比如 日常生活费 / 游戏基金 / 应急资金）；
4. 没分完的余额会自动进「未分配资金」，保证各分区合计 = 总金额；
5. 点「开始记账」。

> 也可以只建一个分区，把全部金额放进去，之后再用「资金调动」拆开。

### 记一笔收入 / 支出

- **记一笔收入**：金额、日期（默认今天）、来源说明、资金分区、备注。
- **记一笔支出**：金额、日期、支出内容、**六个分类之一**、资金分区、备注。

六个固定分类：

| 分类 | 包括 |
| --- | --- |
| 吃饭 | 早餐、午餐、晚餐、零食、饮料、外卖 |
| 生活 | 日用品、洗漱、交通、个人生活开销 |
| 文具 | 书籍、笔、本子、学习与办公用品 |
| 游戏 | 游戏购买、充值、DLC、会员 |
| 周边 | 动漫周边、手办、徽章、立牌 |
| 科技 | 电子设备、数码配件、电脑配件与服务 |

保存后，总余额、该资金分区余额、本月统计、月度总结会**立刻更新**。

### 修改 / 删除账目

- 首页「最近账目」或月度总结的明细里，点击任意一条即可修改；
- 修改/删除都有确认，所有受影响的余额和月报会立即重算；
- 支持补记过去月份的账目，历史月报和后续月份结转会自动跟着变。

### 资金分区与资金调动

- 「资金管理」页可以新增、改名、归档资金分区；
- 新分区从 0 元开始，要用「**资金调动**」从别的分区转钱进来；
- 资金调动只是两个分区之间挪钱，**不算收入、不算支出，总余额不变**；
- 默认不允许把分区花成负数；需要时可在「财务设置 → 允许负余额」打开；
- 有收支或转账记录的分区不能直接删除，只能归档（历史月报会保留它）。

### 财务设置

在「资金管理」右上角「财务设置」里：

- **货币单位**：人民币（默认）/ 美元 / 欧元 / 日元 / 英镑。
  只改变显示符号与小数位，**不做汇率换算**，已记录的数字不变；
- **允许负余额**开关；
- **备份 / 恢复 / 导出 CSV**（只针对记账数据；日程备份在「设置 → 数据」）。

### 月度总结

- 顶部有年份、月份选择器，左侧是历史月份卡片，点击即可切换；
- 显示月初余额、本月收入、本月支出、本月净收支、月末余额（自动结转到下月）；
- 六类支出：金额、占比、与上月比较；环形图 + 占比条；「六类合计 = 本月总支出」有校验；
- 资金分区表：每个分区的月初、收入、支出、转入、转出、月末，合计与全局月末余额一致；
- 自动生成一段文字总结；
- 本月明细可按「支出 / 收入 / 资金调动」切换查看。

**月报什么时候生成**：每月结束自动生成；如果那时程序没开，下次启动会补生成；程序跨月运行时也会补。
月报展示始终以账目明细为准，月报快照只作为生成记录保存。

## 10. 数据与备份

- **完全本地**：不联网、不上传、不需要账号。
- 日程备份：「设置 → 数据 → 立即备份 / 从备份恢复」。
- 记账备份：「资金管理 → 财务设置 → 备份 / 恢复」。
- 日程 CSV：设置 → 导出 CSV / 导入 CSV；记账 CSV：财务设置 → 导出 CSV。
- 恢复备份前，程序会先把当前数据库另存一份，避免二次损失。
- 想换数据位置：设置环境变量 `WEEKLY_PLANNER_HOME` 指向新目录；
  数据目录不可写时程序会明确提示，而不是悄悄写到别处。

> 首次启用记账时，程序会自动把 `planner.db` 备份为 `planner.before-finance-<时间>.db`，防止万一。

## 11. 常见问题

**Q：双击没反应，或者托盘里找不到图标？**
1. 先点任务栏右下角的「^」，看图标是否被折叠；或到「设置 → 个性化 → 任务栏 → 其他系统托盘图标」把「一周日程」打开。
2. 看启动日志：`%TEMP%\WeeklyPlanner-bootstrap.log`（记录到哪一步），以及 `%APPDATA%\WeeklyPlanner\logs\planner.log`。
3. 确认是从桌面/开始菜单图标启动，而不是聊天窗口里的文件卡片。

**Q：开机启动失败，提示 `[WinError 5]`？**
说明当前进程被限制写注册表（通常是受限环境启动）。请从开始菜单启动后再到设置里勾选。

**Q：提醒没有弹？**
- 确认程序正在运行（托盘里有图标）；
- 设置里的「使用 Windows 系统通知」「应用内提醒浮窗」是否打开；
- Windows「请勿打扰 / 通知」总开关是否拦截；
- 错过很久的提醒超过「补发窗口」后不会再补；
- 可以点「发送测试通知」验证链路。

**Q：改了电脑时间 / 睡了一觉，提醒会乱吗？**
不会。程序会检测系统时间的跳变并重排提醒；睡眠唤醒后也会补检查。

**Q：全局快捷键冲突？**
设置里换一个组合（如 `Ctrl+Alt+F8`），被占用时会有提示。

**Q：数据会丢吗？**
每笔操作都会立即写入 SQLite 事务；异常时整体回滚。建议定期用「立即备份」留一份。

**Q：怎么升级？**
覆盖安装新版本即可，数据在 `%APPDATA%` 不受影响；首次启用记账会自动备份日程库。

**Q：怎么卸载？**
托盘退出程序 → 删除 `AppData\Local\Programs\WeeklyPlanner` 与桌面/开始菜单快捷方式。
数据目录 `%APPDATA%\WeeklyPlanner` 可以保留（方便以后恢复）或手动删除。

## 12. 与安卓版互通（JSON）

- 本机「设置 → 数据 → 导出 JSON」，生成一个 JSON 文件；
- 把文件发到手机，安卓版「我的 → 数据 → 恢复备份」选择它；
- 反向：安卓「导出备份」→ 本机「设置 → 导入 JSON」；
- 内容包括任务、计划时间、课程、资金分区、账目、转账、月报；
- 导入是整体替换，导入前建议先「立即备份」；没有自动同步。
