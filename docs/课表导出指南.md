# 课表导出指南：有「导出」键 / 只有「打印」键

> 适用：教务系统可能叫「导出 / 输出 / 下载 / 保存 / 打印」，不同学校不一样。
> 目标：把课表变成「一周日程」能导入的 `.xlsx` / `.csv`，或者文字版 PDF。

---

## 两个入口先分清

| 你看到的按钮 | 优先做法 | 结果 |
| --- | --- | --- |
| **导出 / 输出 / 下载** | 直接导出 Excel | 最省事，优先 `.xlsx` |
| **打印 / 打印预览** | 复制文字，或打印成文字版 PDF | 见下面情况 A/B/C |

如果两个按钮都有，**先试「导出」**；导出只能出 PDF 或图片，再按「打印」的流程处理。

---

# 情况 0：有「导出」键（最省事）

## 1. 用电脑浏览器

手机教务系统经常没有导出按钮，建议用电脑：

1. 登录教务系统；
2. 找到「课表查询 / 我的课表 / 学生课表」；
3. 选对学期；
4. 找按钮：

```text
导出 / 输出 / 下载 / 保存 / 导出 Excel
```

## 2. 格式怎么选

优先顺序：

```text
.xlsx  >  .xls  >  .csv  >  文字版 PDF
```

不要选：

- 图片；
- 扫描版 PDF；
- 手机截图。

如果弹窗让你选：

- 「导出 Excel」→ 选 `.xlsx`；
- 「导出 PDF」→ 只有文字版才有用（Windows 可导，Android 不行）；
- 「打印」→ 不要点，除非没有导出。

## 3. 保存并检查

1. 浏览器下载 `课表.xlsx`；
2. 打开 Excel；
3. 看有没有这些表头之一：

```text
星期一 | 星期二 | … | 星期日
```

或：

```text
课程名称 | 星期 | 节次 | 周次
```

4. 如果是 `.xls`，能打开就不用转；
5. 如果是网页 `.html` 伪装成 `.xls`，Excel 会提示格式不符，点「是」继续，再另存为 `.xlsx`；
6. 如果有多个工作表，优先看「课程明细」这种一行一门的表。

## 4. 发到手机导入

1. 微信/QQ/数据线把文件发到手机；
2. 「我的 → 课表 → 导入课表」；
3. 选文件；
4. 选「使用课表时间 / 自定义每节时间」；
5. 填第 1 周星期一；
6. 预览 → 导入。

## 5. 导出键不能用怎么办

如果「导出」是灰的、点了没反应、只给 PDF：

- 回上一页，找「打印」；
- 按下面的「打印」流程走。

---

# 只有「打印」键：先判断输出

点「打印」后，通常有三种结果：

| 结果 | 能不能直接导入 | 做法 |
| --- | --- | --- |
| 打印预览里**能选中文字** | ✅ 最稳 | 复制 → 粘到 Excel → 保存 xlsx |
| 打印成 **文字版 PDF** | Windows ✅ / Android ❌ | Windows 直接导入 PDF，或复制文字 |
| 打印成 **图片/扫描 PDF** | ❌ 没有 OCR | 先 OCR，或手工录入模板 |

下面按三种情况分别写。

---

# 情况 A：打印预览能选中文字（推荐）

## 1. 打开打印预览

浏览器里按：

```text
Ctrl + P
```

或点教务系统的「打印」按钮。

不要急着点「打印」，先看预览里的表格：

- 鼠标能不能拖选文字？
- 能选中 → 走这一步；
- 选不中 → 看情况 B。

## 2. 复制表格

1. 在打印预览里，从「星期一」拖到「星期日」右下角；
2. `Ctrl + C`；
3. 打开 Excel；
4. 选中 A1，`Ctrl + V`。

## 3. 整理成标准表

粘进去后，通常需要：

1. 删除标题行、学期信息行；
2. 删除空白行；
3. 让表头变成：

```text
星期 | 节次 | 课程名称 | 周次 | 场地 | 教师
```

4. 如果一行里挤了多门课，用「数据 → 分列」拆开；
5. 另存为：

```text
课表.xlsx
```

## 4. 更省事的办法：直接粘贴到 Windows 版

Windows 版「导入课表」里有「从文本粘贴」：

1. 在打印预览里 `Ctrl + A`、`Ctrl + C`；
2. 打开「一周日程」→「导入课表」→「从文本粘贴」；
3. 粘贴 → 解析；
4. 预览没问题就导入。

> 这条只适用于 Windows 版；Android 版没有粘贴入口。

---

# 情况 B：只能打印成 PDF（文字版）

## 1. 打印成 PDF

1. `Ctrl + P`；
2. 打印机选：

```text
Microsoft Print to PDF
```

或：

```text
另存为 PDF
```

3. 保存为 `课表.pdf`；
4. 用浏览器/PDF 阅读器打开，确认**能选中文字**。

## 2. Windows 版直接导入

1. 「导入课表」；
2. 选 `课表.pdf`；
3. 程序会尝试按文字坐标还原表格；
4. 预览 → 选择「使用课表时间 / 自定义每节时间」；
5. 导入。

> 只支持**文字版、方向正常、表头完整**的 PDF。
> 旋转 90°、跨多页拼接、打印时丢了表头的 PDF 可能失败。

## 3. 如果 PDF 导入失败

用「从文本粘贴」兜底：

1. 打开 PDF；
2. `Ctrl + A`、`Ctrl + C`；
3. Windows 版「导入课表」→「从文本粘贴」；
4. 粘贴 → 解析。

## 4. Android 怎么办

Android 不支持 PDF，需要先在电脑上转成 `.xlsx` 或 `.csv`：

1. 在电脑上打开 PDF；
2. 全选复制，粘到 Excel；
3. 整理成标准表；
4. 另存为 `课表.xlsx`；
5. 发到手机，再导入。

---

# 情况 C：打印出来是图片/扫描件

如果 PDF 里选不中文字，说明是图片，程序**不能直接识别**。

三个办法：

## 办法 1：用 OCR 工具

- WPS：PDF → 文字识别；
- Adobe Acrobat：导出 PDF；
- 在线 OCR：注意不要上传含姓名、学号的完整课表到不明网站。

识别后导出 `.xlsx` / `.csv`，再导入。

## 办法 2：手工录模板

用仓库里的模板：

```text
docs/课表模板.xlsx
```

一行一门课：

```csv
星期,节次,课程名称,周次,场地,教师
星期一,1-2,高等数学,1-16周,图一,张老师
```

保存为 `.csv`，直接导入。

## 办法 3：让同学发一份 Excel

如果同学能从教务系统导出 Excel，直接用他的文件，改掉姓名/学号即可。

# 打印时的常见坑

## 1. 打印预览没有表头

有些系统打印时把「星期一…星期日」隐藏了。

处理：

- 换浏览器（Edge/Chrome）再试；
- 打印设置里勾选「背景图形」；
- 纸张方向改「横向」；
- 还不行就复制网页表格，不要用打印。

## 2. 表格被拆成多页

打印预览里如果一页放不下：

- 缩放选「适应页面」；
- 或直接复制 HTML 表格到 Excel，不要打印。

## 3. 打印出来是乱码/空白

- 换浏览器；
- 关闭打印精简模式；
- 用「另存为 PDF」而不是系统打印机。

## 4. PDF 能选中文字，但导入报错

通常是：

- 表头被拆成两行；
- 大节时间被隐藏；
- 周次写法太特殊。

处理：

1. 用「从文本粘贴」；
2. 或复制到 Excel 整理成标准表；
3. 再导入。

---

# 标准表格式（最稳）

不管打印成什么，最后整理成这个表最稳：

```csv
星期,节次,课程名称,周次,场地,教师
星期一,1-2,高等数学,1-16周,图一,张老师
星期一,3-4,大学英语,1-8周,教二,李老师
星期二,5-6,无机化学,1-16周(双),实验楼,王老师
```

要点：

- **星期**：星期一…星期日；
- **节次**：`1-2`、`3-4`，不要写「第一大节」也可以；
- **周次**：`1-16周`、`1-16周(双)`、`5周,11周`；
- **场地/教师**：可以不填；
- 一行一门课。

保存为：

```text
课表.xlsx
```

或：

```text
课表.csv
```

# 导入步骤

## Windows

1. 打开「一周日程」；
2. 右上角「导入课表」；
3. 选 `.xlsx` / `.csv` / 文字版 `.pdf`；
4. 选「使用课表时间 / 自定义每节时间」；
5. 填第 1 周星期一；
6. 预览 → 导入。

## Android

1. 「我的 → 课表 → 导入课表」；
2. 选 `.xls` / `.xlsx` / `.csv`（不支持 PDF）；
3. 选时间来源；
4. 填第 1 周星期一；
5. 预览 → 导入到日程。

---

# 检查清单

- [ ] 文件是 `.xlsx`、`.csv` 或文字版 `.pdf`；
- [ ] 有「星期一…星期日」表头，或有「课程名称/星期/节次/周次」列；
- [ ] 一门课一行，周次能看懂；
- [ ] 没有合并单元格；
- [ ] PDF 能选中文字；
- [ ] 导入预览里的课程数量、时间对得上。
