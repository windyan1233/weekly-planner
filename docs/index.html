一周日程

纯本地周计划 + 记账 · Windows / Android

不联网、不登录、不收集数据

日程、课表、提醒、记账、月报都在本机。需要换设备时用 JSON 手动导入导出。

下载最新版 查看源码

Windows 当前包未签名，SmartScreen 可能提示「未知发布者」；已申请 SignPath Foundation 免费开源签名，通过后会发布签名版本。

Windows

下载 zip，解压后运行 WeeklyPlanner.exe。数据保存在 %APPDATA%\WeeklyPlanner。

下载 Windows 包

Android

下载 APK，允许「未知来源」后安装。不申请 INTERNET 权限，数据只在本机。

下载 Android APK

功能

  • 周视图 / 列表视图
  • 一个任务多个计划时间
  • 截止前一天提醒
  • 课表导入（xls / xlsx / csv）
  • 文字版 PDF 课表（Windows）
  • 资金分区与转账
  • 六类支出，可自定义
  • 月度报表与结余结转
  • JSON 双端互通
  • MIT 开源
