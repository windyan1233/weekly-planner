三步就能用

Windows 解压 zip；Android 安装 APK，允许未知来源。

允许通知

Android 首次打开允许通知和精确提醒，否则截止提醒不会弹。

导入课表 / 记第一笔

「我的 → 课表 → 导入课表」；记账页右下角「记一笔」。

常见问题

先看这几条

数据会上传吗？

不会。两端都不联网，Android 没有 INTERNET 权限；数据是本地 SQLite，备份文件需要你自己保管。

Windows 为什么提示「未知发布者」？

当前 Windows 包未做代码签名。已申请 SignPath Foundation 免费开源签名，通过后会发布签名版本；你可以用 Release 里的 SHA256 校验文件。

两端怎么同步？

没有自动同步。一端「数据 → 导出 JSON」，传到另一端「数据 → 导入 JSON」；导入是整体覆盖，导入前先备份。

课表 PDF / 图片能导入吗？

Windows 支持文字版 PDF；扫描件、图片、旋转/跨页 PDF 不能可靠识别。Android 不支持 PDF，建议先转 xlsx/csv。
