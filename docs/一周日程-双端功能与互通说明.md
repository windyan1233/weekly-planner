# 一周日程 · 双端功能与互通说明

> 适用版本：Windows 1.0.2 / Android 1.0.14  
> 更新日期：2026-10-24  
> 说明：本文只描述现有功能与限制，不涉及后续开发承诺。

---

## 0. 一句话概括

「一周日程」是一个**纯本地**的周计划 + 记账工具：

- **Windows 版**：Python + PySide6，适合电脑上长时间规划、批量导入课表、做月度账；
- **Android 版**：Kotlin + Jetpack Compose + Room，适合手机随身查看、打卡、记账；
- 两端通过**同一套 JSON 格式**互换数据，不依赖服务器，不需要登录，不联网。

---

## 1. 平台与数据位置

| 项目 | Windows 版 | Android 版 |
| --- | --- | --- |

## 2. Windows 版功能

### 2.1 日程与任务

- **周视图**：周一～周日 7 列，左侧时间轴，课程以背景色块显示，任务/计划/截止叠加在时间轴上；
- **任务字段**：标题、备注、分类（学习/工作/生活等）、优先级（普通/重要/紧急）、截止时间、完成状态；
- **多计划时间**：一个任务可以挂多个计划时间，互相独立；
- **截止提醒**：截止日期前一天提醒；
- **筛选与搜索**：按分类、状态（全部/未开始/进行中/已完成）、优先级（全部/普通/重要/紧急）、仅看逾期、关键词搜索；
- **逾期列表**：未完成且已过截止的任务单独标记；
- **课程背景**：导入的课程按周次展开到具体日期，显示在周视图背景层，不占任务数据；
- **快速操作**：新建任务、编辑、完成/取消完成、删除、改期。

### 2.2 提醒

- **截止提醒**：默认截止日前一天 **09:00**，时间可改；
- **计划提醒**：计划时间前 **N 分钟**（默认 10 分钟，可改）；
- **错过补发**：程序未运行时错过的提醒，重新打开后在补发窗口内补一次（默认 6 小时，可改）；
- **稍后提醒**：可设置稍后间隔（默认 2 分钟）；
- **通知通道**：
  - Windows 系统 Toast 通知（首选）；
  - 应用内提醒浮窗（可单独关闭）；
  - 托盘气泡（系统通知不可用时的兜底）；
- **托盘常驻**：关闭窗口可最小化到托盘，提醒不中断；
- **开机启动**：可选；
- **全局快捷键**：可注册一个系统级快捷键呼出窗口（默认关闭，可设置组合键）。

### 2.3 记账

- **资金分区**：可建多个账户/分区，每个分区有初始余额；
- **收入/支出**：金额、分类、账户、标题、备注、日期；
- **支出分类**：默认六类（吃饭/生活/文具/游戏/周边/科技）；「自定义分类版」支持改分类；
- **转账**：分区之间转账，不计入收入/支出；
- **月度总结**：按月统计收入、支出、分类占比，支持**上月结余结转**；
- **历史记录**：按月查看、编辑、删除；
- **导出 CSV**：方便用 Excel 复盘。

### 2.4 课表导入

- 支持 `.xls` / `.xlsx` / `.csv` / 文字版 `.pdf`；
- 支持「从文本粘贴」：PDF/网页/Excel 里复制表格文本直接粘贴解析；
- 解析后先预览，确认课程、星期、时间、周次、地点、教师；
- **时间来源二选一**：
  - 「使用课表时间」——用课表里写的大节时间；
  - 「自定义每节时间」——8 个大节分别设置起止时间；
  - 课表里没有时间时，强制走「自定义」，否则不允许导入；
- 支持多工作表 `.xlsx`：优先找含「课程名称 + 星期」表头的明细表（如「课程明细」），找不到再用第一个工作表；
- 导入前可勾选「清空已有课程」；
- 「清空课程表」只删课程和上课记录，不影响任务、提醒、记账。

### 2.5 数据与备份

- **备份数据库**：把 `planner.db` / `finance.db` 备份成 `.db` 文件；
- **从备份恢复**：覆盖前会先另存当前库；
- **导出/导入 CSV**：任务、记账的表格交换；
- **导出/导入 JSON**：与 Android 互通（见第 5 节）；
- **打开数据文件夹**：直接定位到 `%APPDATA%\WeeklyPlanner`；
- **作者的话**：关于页里的说明与联系方式。

### 2.6 设置与其他

- 主题：跟随系统 / 浅色 / 深色；
- 提醒规则、通知开关、声音、稍后间隔、补发窗口；
- 关闭到托盘、开机启动、启动时最小化；
- 全局快捷键；
- 版本信息、作者说明。

## 3. Android 版功能

### 3.1 底部导航

四个 Tab：**日程 / 记账 / 月报 / 我的**。

### 3.2 日程：列表模式

- 顶部日期条：周一～周日，显示日期，选中日高亮；
- 左右箭头或左右滑动切换周；
- 「今日概览」：当天几节课、约多少小时、几个计划、几个截止；
- 分组列表：
  - **课程**：课程名、地点、起止时间；
  - **计划时间**：任务名、分类/优先级、计划时刻，可勾选完成；
  - **截止**：截止时间；
  - **已逾期**：未完成且已过截止；
  - **还没安排时间**：没有计划时间、没有截止的待办；
- 点任务行打开任务详情；点圆圈切换完成。

### 3.3 日程：周视图（默认）

- 7 列（周一～周日）× 时间轴（07:00–23:00），可上下滚动；
- 打开时自动滚到当前小时；
- **课程**：按起止时间画色块，显示课程名、时间、地点；
- **计划时间**：任务按 45 分钟默认时长画块，颜色按优先级；
- **截止**：细红线 + 右端红点，点线打开任务；
- **重叠规则**：同一天的块**完全对齐叠放**，不横向错开；课程在下、任务在上，任务完整盖住重叠段；
- 点课程块弹出课程详情（名称、时间、地点、教师）；点任务/截止块打开任务；
- 左右滑动切换上一周/下一周，带轻微滑入 + 淡入动画；
- 选中的那天列有浅色高亮；
- 视图切换在「我的 → 日程视图」，可选列表/周视图，默认周视图，选择会记住。

### 3.4 提醒

- 截止提醒：截止日前一天，时间可设（默认 09:00）；
- 计划提醒：计划时间前 N 分钟（默认 10 分钟）；
- 需要通知权限；Android 12+ 需要「精确闹钟」权限；
- 开机、时区变化后自动重排提醒；
- WorkManager 每 6 小时兜底补排；
- 提醒以系统通知呈现（没有应用内浮窗）；
- 点通知可打开对应任务。

### 3.5 记账与月报

- 资金分区（账户）新增、改名、初始余额；
- 收入/支出：金额、支出分类、账户、标题、备注、日期；
- **支出分类**：默认六类（吃饭/生活/文具/游戏/周边/科技），可在「我的 → 支出分类」里；
  - **添加分类**：输入名称，颜色自动分配；
  - **改名**：只改显示名，不动 key，已有流水不受影响；
  - **删除**：至少保留 1 个；删掉的分类，旧流水显示为「其他」；
  - **恢复默认**：一键回到六类；
  - 记账页、快速记账、月报、流水明细都会同步；
- 分区之间转账；
- 月度总结：收入、支出、分类占比、上月结余结转；
- 历史流水：按月查看、编辑、删除；
- 记账页顶部三列汇总：本月收入/支出/结余（不换行）。

### 3.6 课表

- 导入 `.xls` / `.xlsx` / `.csv`（**不支持 PDF**）；
- 多工作表 `.xlsx`：优先「课程明细」这类扁平表；
- 支持网格课表和一行一课的 CSV；
- 导入时可选择「使用课表时间 / 自定义每节时间」；课表没时间时必须自定义；
- 导入后显示课程数、上课次数；
- 「清空课程」只删课程，不影响任务、提醒、记账；
- 课程会显示在列表模式和周视图里。

### 3.7 数据与「我的」

- **导出 JSON**：把任务、计划、课程、记账、报表打包成一个 JSON；
- **导入 JSON**：从文件选择，或从其他应用「用一周日程打开」；
- 支持 external `VIEW` / `SEND`：QQ/微信/文件管理器里点 JSON → 选择「一周日程」→ 弹确认导入；外部打开上限 20MB；
- 数据目录、当前课程数、当前账目数；
- 「支出分类」管理：添加/改名/删除/恢复默认；
- 权限状态：通知、精确闹钟；
- 作者的话、版本号；
- 没有 INTERNET 权限，数据只在本机。

## 5. 双端互通（JSON）

### 5.1 格式

- 格式名：`weekly-planner-exchange`
- 版本：`1`
- 根字段：

```json
{
  "format": "weekly-planner-exchange",
  "version": 1,
  "source": "windows" | "android",
  "app": "weekly-planner" | "weekly-planner-android",
  "exportedAt": 1760000000000,
  "tasks": [],
  "plans": [],
  "accounts": [],
  "transactions": [],
  "transfers": [],
  "reports": [],
  "courses": [],
  "courseSessions": []
}
```

单位约定：

- 金额：**分**（`amountCents`、`openingCents`）；
- 时间：**epoch 毫秒**（`dueAt`、`planAt`、`occurredAt`、`createdAt`）；
- 星期：`0 = 周一 … 6 = 周日`；
- 课程时间：`startMinutes`/`endMinutes` 为当天 0 点起的分钟数；
- 课程日期：`day` 为 `yyyy-MM-dd`；
- 优先级：Windows 内部 `normal/important/urgent`，导入时映射为「普通/重要/紧急」。

### 5.2 字段

#### tasks

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 任务 id |
| title | string | 标题 |
| note | string | 备注 |
| kind | string | 分类（学习/工作/生活…） |
| priority | string | 普通/重要/紧急（或 normal/important/urgent） |
| dueAt | number/null | 截止时间（毫秒） |
| done | boolean | 是否完成 |
| createdAt / updatedAt | number | 创建/更新时间 |

#### plans

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 计划 id |
| taskId | number | 所属任务 |
| planAt | number | 计划时间（毫秒） |

#### accounts

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 账户 id |
| name | string | 名称 |
| openingCents | number | 初始余额（分） |
| sortOrder | number | 排序 |
| archived | boolean | 是否归档 |
| createdAt | number | 创建时间 |

#### transactions

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 流水 id |
| type | string | `expense` / `income` |
| amountCents | number | 金额（分，正数） |
| categoryKey | string | 支出分类 key；收入为空 |
| accountId | number | 账户 id |
| title / note | string | 标题/备注 |
| occurredAt | number | 发生时间（毫秒） |
| createdAt | number | 创建时间 |

#### transfers

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 转账 id |
| fromAccountId / toAccountId | number | 转出/转入账户 |
| amountCents | number | 金额（分） |
| note | string | 备注 |
| occurredAt / createdAt | number | 时间 |

#### reports

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| month | string | `yyyy-MM` |
| incomeCents / expenseCents | number | 收入/支出 |
| openingCents / closingCents | number | 期初/期末 |
| categoryJson | string | 分类占比 JSON 字符串 |
| createdAt | number | 生成时间 |

#### courses

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 课程 id |
| name / teacher / location | string | 课程信息 |
| descriptor | string | 描述 |
| color | string | 颜色，如 `#6C8AE4` |
| createdAt | number | 创建时间 |

#### courseSessions

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | number | 上课记录 id |
| courseId | number | 所属课程 |
| day | string | `yyyy-MM-dd` |
| startMinutes / endMinutes | number | 当天起止分钟 |

### 5.3 操作步骤

#### Windows → Android

1. Windows：设置 → 数据 → **导出 JSON**，保存文件；
2. 把 JSON 发到手机（微信/QQ/数据线/网盘）；
3. 手机：我的 → 数据 → **导入 JSON**，选文件；
4. 或在文件管理器/聊天软件里点 JSON → 选择「一周日程」打开 → 确认导入；
5. 导入完成后核对：任务数、课程数、账户余额、流水中是否齐全。

#### Android → Windows

1. 手机：我的 → 数据 → **导出 JSON**；
2. 把 JSON 发到电脑；
3. Windows：设置 → 数据 → **导入 JSON**，选文件；
4. 核对任务/课程/记账/报表。

### 5.4 覆盖规则与注意事项

> **导入是整体覆盖，不是合并。** 导入前先导出备份。

- Windows 导入会先清空任务/计划/课程/上课记录/账户/流水/转账/报表，再写入 JSON 内容；
- Android 导入同样先清空上述数据，再写入；
- **导入会保留本机设置**（提醒时间、主题、日程视图、自定义支出分类），不会再重置；
- **旧备份没有 accounts 字段时**：Android 会**保留本机资金分区**，避免把总资产清空；Windows 会按空账户处理，正常导出都包含 accounts，一般不会遇到；
- JSON 里的 `plans.taskId`、`courseSessions.courseId` 必须能对应到同一文件里的 `tasks`/`courses`，否则会变成孤立记录；
- 重复导入不会产生重复数据（每次先清空），但会覆盖导入后在本机新增的内容；
- 金额单位是**分**，不是元；手工改 JSON 时注意；
- Android 从外部应用打开 JSON 上限 **20MB**；更大文件请从「我的 → 数据 → 导入」走文件选择；
- 旧版 Android 的 `app` 字段可能是 `weekly-planner-android`，两端都兼容。

## 6. 课表导入

### 6.1 支持矩阵

| 格式 | Windows | Android | 说明 |
| --- | --- | --- | --- |
| `.xls` | ✅ | ✅ | 老 Excel；合并单元格可能丢内容 |
| `.xlsx` | ✅ | ✅ | 支持多工作表 |
| `.csv` / `.txt` | ✅ | ✅（csv/txt） | 一行一门课的扁平表最稳 |
| 文字版 `.pdf` | ✅ | ❌ | Windows 用 PDF 文字层还原表格 |
| 扫描版/图片 PDF | ❌ | ❌ | 没有 OCR |
| 图片/照片 | ❌ | ❌ | 没有 OCR |
| 从文本粘贴 | ✅ | ❌ | Windows 专用兜底 |

### 6.2 能识别的两种结构

#### A. 网格课表

```text
        星期一      星期二      …
第一大节 (01,02) 08:30-10:05
        高等数学    大学英语
        张三        李四
        1-16周      1-8周
        图一        教二
```

要求：

- 有「星期一…星期日」表头（至少 5 天）；
- 有大节行，如「第一大节 (01,02)」，时间可写可不写；
- 单元格里每门课包含：课程名、周次（如 `1-16周`、`1-16周(单)`、`5周,11周`）、节次（如 `[01-02节]`）；
- 地点/教师可有可无。

#### B. 一行一课的扁平表

```csv
星期,节次,课程名称,周次,场地,教师
星期一,3-4,体能训练（1）,4-6周(双),7-16周,第一田径场,韩林
```

要求：

- 表头至少包含：**课程/课程名称 + 星期 + 节次 + 周次**；
- 可选：时间、地点/场地/教室、教师；
- 一行一门课，最适合 Excel/CSV。

> 多工作表 `.xlsx`：两端都会优先找「课程名称 + 星期」表头的扁平表（如「课程明细」）；找不到才用第一个工作表。

### 6.3 没有时间的课表

- 网格课表的大节行可以没有 `08:30-10:05`；
- 导入时会自动切到「自定义每节时间」，要求你为 8 个大节设置起止时间；
- 不设置就不能导入，避免课程全挤在 00:00；
- 扁平表没有「时间」列时同样处理。

### 6.4 什么课表导不进来

| 现象 | 原因 | 解决办法 |
| --- | --- | --- |
| 提示「没有找到第一大节 (01,02) 这样的作息行」 | 网格表没有「大节」行，且没有可用的扁平明细表 | 用「课程明细」表；或整理成 CSV；Windows 可复制文本粘贴 |
| 提示「没有找到星期一…星期日表头」 | 表头不是标准星期，或表格被拆成图片 | 改成标准表头；或转 CSV |
| 提示「没有解析出任何课程」 | 节次/周次缺失、格式太特殊 | 补「节次」「周次」列；按扁平表整理 |
| 扫描版 PDF / 拍照课表 | 没有文字层，程序不做 OCR | 先用其他工具 OCR 成文字/Excel，再导入 |
| Android 选 PDF | 安卓端没有 PDF 解析 | 先转 `.xlsx` / `.csv`；或在 Windows 导入后导 JSON 给手机 |
| 旋转 90°、跨 4 页打印的 PDF | 文字层有字，但列错位、跨页无表头、连字符丢失 | 用同源 `.xlsx`；或先整理成 CSV |
| `.xls` 合并单元格多 | 合并区域可能重复/漏读 | 另存为 `.xlsx` 或 CSV，取消合并 |
| 加密/损坏/超大文件 | 打不开或超限 | 解密、另存、拆分 |
| `.numbers` / `.docx` / 网页 | 不支持这些容器 | 导出为 `.xlsx` / `.csv` |
| 聊天软件缓存文件没有扩展名 | 程序按扩展名判断类型 | 重命名为 `.xlsx` / `.csv` |
| 课表只有图片、没有文字 | 无 OCR | 手工录入，或先 OCR 成 CSV |

### 6.5 推荐的最稳格式

1. Excel 里建一张表，表头：

```text
星期 | 节次 | 课程名称 | 周次 | 场地 | 教师
```

2. 一行一门课；
3. 节次写 `3-4`，周次写 `1-16周` 或 `1-16周(双)`；
4. 另存为 `.xlsx` 或 `.csv`；
5. 导入时按需选「使用课表时间」或「自定义每节时间」。

## 7. 常见问题

**Q：为什么 Android 没有 PDF 导入？**  
A：安卓端没有内置 PDF 文本解析库；PDF 版式差异大，先转 `.xlsx`/`.csv` 最稳。

**Q：为什么 Windows 能选 PDF，但我的 PDF 还是失败？**  
A：只支持**文字版、方向正常、表头完整**的 PDF；扫描件、旋转打印件、跨页拼接件会失败。

**Q：导入 JSON 后课程/账户没了？**  
A：导入是整体覆盖；如果 JSON 里没有对应数据，本机就会被清空。导入前先导出备份；旧版无 `accounts` 时 Android 会保留本机账户。

**Q：Android 导入后提醒时间/主题/自定义分类会变吗？**  
A：不会。导入只覆盖任务、课程、记账和报表；提醒时间、主题、日程视图、自定义支出分类都保留本机设置。

**Q：两端能同时改吗？**  
A：不能自动同步。建议以一端为主，改完导出 JSON 覆盖另一端；同时改会互相覆盖。

**Q：数据会上传吗？**  
A：不会。两端都没有 INTERNET 权限/不联网，数据只在本机；JSON 只在你选择导出时写到文件。

## 8. 隐私与安全

- 不收集账号、不埋点、不联网；
- Android 没有 `INTERNET` 权限；
- 数据明文存储，手机丢失/电脑被访问时可能被读取；
- Android `allowBackup=true` 可能把数据库纳入系统云备份，介意可在系统设置关闭；
- 备份 JSON/SQLite 文件请自己保管，不要发到公开群。

## 9. 已知限制

- iOS 版暂无（需要 Mac + Xcode 重写，不能直接移植）；
- 无 OCR，图片/扫描件课表不能直接导入；
- Android 无 PDF 课表导入；
- 自定义支出分类不写入 JSON：导到 Windows 时只保留 `categoryKey`，两端要有同名分类才能显示名称，否则显示「其他」；
- Windows 自签名证书在别的电脑上仍显示「未知发布者」；
- 两端不做自动云同步，只能手动 JSON 互通。
