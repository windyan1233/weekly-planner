# 下载

安装包发布在 GitHub Releases：

- 最新版本：https://github.com/windyan1233/weekly-planner/releases/latest
- 全部版本：https://github.com/windyan1233/weekly-planner/releases

## 平台

- **Windows**：下载 `一周日程-*-windows.zip`，解压后运行 `WeeklyPlanner.exe`；
- **Android**：下载 `一周日程-*-android.apk`，允许「未知来源」后安装。

## 代码签名

Windows 版本正在申请 **SignPath Foundation** 的免费开源代码签名：

https://signpath.org/

当前 Windows 发布包**尚未签名**，SmartScreen 可能提示「未知发布者」；签名通过后会发布新的签名版本，已发布的旧包不会被静默替换。

## 校验

每个 Release 附带 `SHA256SUMS.txt`，下载后可核对文件完整性。
