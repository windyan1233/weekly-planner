# 一周日程（Android）使用说明

> 版本 1.0.14 · 纯本地、不联网、不需要账号

## 1. 安装

1. 把 `一周日程-1.0.14-android.apk` 传到手机（微信/QQ 传文件、数据线拷贝、网盘均可）；
2. 在手机上点击 APK 安装；
3. 如果提示「未知来源」，在系统弹窗里选择允许本次安装；
4. 安装完成后打开「一周日程」。

> 这是 release 签名包，可直接覆盖 1.0.13；以后升级也要用同一个签名，否则需要先卸载旧版。

## 2. 首次打开

- 允许**通知**权限：没有它，截止提醒不会弹出；
- Android 12 及以上建议允许「**闹钟和提醒**」：在「我的 → 权限与后台 → 精确提醒 → 去设置」里打开；
- 默认已经有一个「现金」资金分区，可以在「我的」里改名或新增。

## 3. 日程

### 新建任务
点右下角「新建任务」：

1. 填名称（必填），备注可选；
2. 选分类（学习/工作/生活）和优先级（普通/重要/紧急）；
3. 打开「截止时间」开关，选日期和时间——程序会在**截止前一天**提醒你；
4. 「添加计划时间」可以加一个或多个时间点，每个都会单独提醒（默认提前 10 分钟）；
5. 保存。

### 看日程
- 默认是**周视图**：7 列 × 07:00–23:00，课程、计划、截止画成色块；
- 点色块看详情，点任务/截止块打开任务；
- **左右滑动**切换上一周/下一周；点「回到本周」快速回来；
- 想用列表：**我的 → 日程视图 → 列表**；
- 列表按「计划时间 / 截止 / 已逾期 / 还没安排时间」分组；
- 点任务打开详情，可以完成、编辑、删除。

### 提醒
- 截止提醒：截止日期的前一天，默认 09:00（「我的 → 提醒设置」可改）；
- 计划提醒：计划时间前 N 分钟（默认 10 分钟，可改 5/10/15/30）；
- 点通知会直接打开对应任务；
- 手机重启、应用更新、改时区后会自动重新安排提醒；
- 系统限制精确闹钟时，提醒可能延迟几分钟，程序会在「我的」里提示。

## 4. 导入课表

1. 在教务系统点「导出」，保存成 `.xls` / `.xlsx` / `.csv`；
2. 打开「我的 → 课表 → 导入课表」，选择文件；
3. 选择「使用课表时间」或「自定义每节时间」——课表里没写时间时，必须自己设置每节课的起止时间；
4. 填**这学期第 1 周的星期一**（填错会整体偏移）；
5. 预览课程列表，点「导入到日程」；
6. 回到「日程」，周视图里会显示课程色块；列表模式每天会多出「课程」分组。

课程不参与任务和提醒；换学期再导入一次即可（默认整体替换），也可以「清空课程」。

## 5. 记账

### 先设资金分区
「我的 → 资金分区 → 添加资金分区」：填名称（例如 饭卡、生活费）和初始余额。
点已有的分区可以修改名称和初始余额；总余额 = 各分区初始余额 + 收入 − 支出。

### 记一笔
点「记账」页右下角「记一笔」：

- 选**支出**：填金额、选支出分类（默认六类：吃饭/生活/文具/游戏/周边/科技）、选资金分区、名称选填；
- 选**收入**：填金额、选资金分区、名称选填；
- 选**转账**：选转出/转入分区，填金额；
- 日期默认今天，可以改；保存后余额立即更新。

### 自定义支出分类
「我的 → 支出分类」：

- **添加分类**：输入名称，颜色自动分配；
- **改名**：只改显示名，已有流水不受影响；
- **删除**：至少保留 1 个；删掉的分类，旧流水显示为「其他」；
- **恢复默认**：回到六类。

### 查看与修改
- 记账页顶部显示总余额、本月支出/收入/结余；
- 支出分类有占比条；
- 本月明细按时间倒序，点一条可以修改金额/分类/备注，或删除。

## 6. 月度总结

- 底部「月报」页：本月收入、支出、结余、期初余额、期末余额；
- 六类支出占比；
- 期末余额会自动结转到下个月的期初；
- 「保存本月报表快照」把当前结果存进历史月报；
- 历史月报可以点开回看。

## 7. 与 Windows 版互通 / 备份

「我的 → 数据」：

- **导出备份**：生成 JSON 文件（任务、计划时间、课程、账目、资金分区、月报）；
- **恢复备份**：选择 JSON 后**整体替换**当前数据；
- 这个 JSON 和 Windows 版「设置 → 导出 JSON / 导入 JSON」是同一个格式，可以互相导入；
- 没有自动同步：需要时手动导出、传到另一端、再导入；导入前先备份当前数据；
- 微信/文件管理器里长按 JSON →「用其他应用打开」→「一周日程」，也能直接导入；
- 建议换手机、刷机、卸载前先导出备份。

## 8. 常见问题

**提醒不准时？**
检查「我的 → 权限与后台」：通知权限是否开启、精确提醒是否允许；部分手机（小米/华为/OPPO/vivo）还需要在系统设置里允许「自启动」「后台运行」。

**收不到通知？**
确认通知权限；检查系统里是否把本应用的通知设为静音/隐藏；省电模式可能延迟提醒。

**数据存在哪？**
只存在手机本地应用数据库里，不联网、不需要账号；卸载应用会删除数据。

**和 Windows 版能同步吗？**
没有自动同步，但可以手动 JSON 互通：一端「数据 → 导出 JSON」，传到另一端「数据 → 导入 JSON」。导入前先备份。

## 9. 开发与构建

源码在仓库的 `android/` 目录。

```bash
cd android
./gradlew test
./gradlew assembleDebug
```

要求：JDK 17、Android SDK 34、Gradle 8.7（仓库带 wrapper）。Release 签名配置见 `android/README.md`，不要把 `keystore.properties` 提交到仓库。
